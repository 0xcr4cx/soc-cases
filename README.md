## SOC Cases
This repository contains Security Operations Center (SOC) case studies completed as part of cybersecurity training and hands-on analysis. 
Each case study focuses on investigating real-world security incidents, documenting findings, 
identifying indicators of compromise (IOCs), and providing remediation recommendations.

## Topics Covering
- Phishing Email Analysis 
- Email Header Investigation
- Threat Hunting
- Malware Indicators
- Incident Response
- Network Traffic Analysis
- Security Monitoring
- Digital Forensics Fundamentals

## Purpose 
The purpose of this repository is to showcase practical SOC analyst skills through structured investigations and technical reporting. 
It serves as a portfolio of hands-on cybersecurity case studies and security analysis exercises.

## Disclaimer 
These case studies are created for educational and portfolio purposes only. 
Any data used has been sanitized and does not contain sensitive or private information.
